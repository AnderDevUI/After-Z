# 🎮 After-Z - Roblox Studio Environment

## 📁 Estructura del Juego

Este repositorio simula la estructura completa de un proyecto de Roblox Studio.

### 🏗️ Servicios Principales

- **Workspace** - Objetos 3D y físicos
- **ReplicatedStorage** - Datos cliente-servidor
- **ServerScriptService** - Scripts del servidor
- **StarterPack** - Items iniciales
- **StarterPlayer** - Configuración del jugador
- **PlayerScripts** - Scripts locales
- **PlayerGui** - Interfaces gráficas
- **Lighting** - Iluminación
- **SoundService** - Audio
- **Teams** - Equipos
- **ServerStorage** - Assets del servidor
- **Chat** - Sistema de chat

### 📂 Estructura

```
Game/
├── Workspace/
├── ReplicatedStorage/
├── ServerScriptService/
├── StarterPack/
├── StarterPlayer/
├── PlayerScripts/
├── PlayerGui/
├── Lighting/
├── SoundService/
├── Teams/
├── ServerStorage/
└── Chat.meta.json
```
